## About this org
This GitHub organization is dedicated to preserving, maintaining, and supporting addons for legacy versions of Garry's Mod, primarily Garry's Mod 12, as well as Garry's Mod 10 & 11.

**Note: While Garry's Mod 10-12 are within the scope of this org, Garry's Mod 12 is the primary focus.**

Contributions are welcome, as long as they're not vibe-coded!
